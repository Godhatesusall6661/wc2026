# ⚽ Прогнозист ЧМ-2026

Сайт конкурса прогнозистов: участники сами вводят прогнозы на матчи,
расписание и результаты подтягиваются автоматически, очки считает база.
Заменяет Excel-табличку организатора.

**Запуск с нуля — см. [SETUP.md](SETUP.md).**

## Как устроено

```
GitHub Pages (статика, React+Vite)
        │  RPC через PostgREST
        ▼
Supabase Postgres ← вся логика: дедлайны, очки, лидерборд (schema.sql)
        ▲
        │  upsert результатов (service key)
GitHub Actions cron (каждые 20 мин) ← football-data.org + The Odds API
```

- Вход без паролей: имя + личная ссылка `#t=<token>`.
- Прогноз можно менять до свистка; чужие прогнозы видны после начала матча.
- Правила очков — в одной функции `match_points` в `supabase/schema.sql`
  (и её зеркало для отображения в `src/Matches.tsx`).
- Выбор чемпиона перед 1/4: +5 за победу команды в полуфинале, +5 в финале.

## Команды

```bash
npm install        # один раз
npm run dev        # локальная разработка
npm run build      # проверка сборки (tsc + vite)
npm run sync       # синк расписания/результатов (нужны env, см. SETUP.md)
```
